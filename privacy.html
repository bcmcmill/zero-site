Privacy policy

  • In force from: 2026-10-03
  • Applies to: the Zero application and everyone who runs it

What Zero is

Zero is debt-payoff planning software that runs entirely on the user's own device. It is single-tenant by design: each installation serves one household, holds only that household's data, and has no connection to any other installation.

There is no Zero service. No servers are operated, no accounts are created, and no copy of anyone's financial data is held anywhere outside the device the software runs on.

What Zero collects

Only what the user enters or explicitly connects:

  • Debts: balance, interest rate, minimum payment, due date, credit limit, promotional terms.
  • Income and spending, either entered directly or imported from statements the user supplies.
  • Transactions, balances, minimum payments, interest rates and due dates for accounts the user chooses to connect through the account aggregator.

Zero collects no data about anyone other than its user, and has no mechanism to.

Where that data goes

Nowhere, except where the user sends it.

  • It is stored on the user's own device, in a directory outside the application's program files, encrypted at rest.
  • It is never transmitted to the developer. There is no server to transmit it to.
  • Zero contains no analytics, no telemetry, no crash reporting and no third-party scripts.

Exactly three kinds of traffic leave the device, and only these:

  1. The account aggregator (Plaid), for accounts the user explicitly connects, under the user's own agreement with that company. Their privacy policy governs what they hold.
  2. Institution websites, where the user signs in on their bank's own page during linking. That page is neither hosted nor scripted by Zero, and Zero cannot read what is typed on it.
  3. Font files from a public CDN, which carry no personal data.

Consent

Nothing is collected without an explicit act: entering a figure, importing a file, or completing an institution's own linking flow. Connecting an account requires completing the aggregator's consent screen, which states what will be shared. No account is connected by default, and none is connected automatically.

A rate reported by an aggregator is presented for review rather than applied, because applying it silently would change the payoff plan around a figure the user never saw.

Credentials

Zero never holds a bank or lender password. Linking is performed entirely through the aggregator's own flow. Aggregator keys and access tokens are held in the operating system's credential store, never in Zero's own files.

Security

Zero's data is encrypted with a key derived from the user's passphrase, which is not stored anywhere. Until the user unlocks the application, Zero cannot read its own files, and neither can any other process running on the device. Opening Zero requires two factors: that passphrase, and a time-based one-time code. No data is served and no institution can be connected until both are configured.

Retention and deletion

Data is retained until the user deletes it. There is no background copy, in any location. A single command disconnects every institution at the aggregator and deletes everything held locally — the connection is revoked as well as the files removed, so the institution stops sending data rather than Zero merely forgetting where it went.

The full schedule is set out in Zero's data retention and disposal policy, available on request.

Rights

Because the only subject of the data is the person running the software, the usual rights of access, correction, export and erasure are exercised directly: the data is a set of files in a directory under the user's control, the application can display and edit all of it, and one command removes it.

Changes

This policy is versioned alongside the application. Material changes are reflected here.

Contact

Privacy and security enquiries, including from financial institutions, are handled at the address registered with Plaid for this application, and via the public repository for anything that is not confidential.
