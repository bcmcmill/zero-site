# Zero — site

The public page for [Zero](https://bcmcmill.github.io/zero-site/), a personal debt-payoff planner,
and its privacy policy.

This repository holds only those pages. Zero itself is not public.

`privacy.html` is generated from the policy in the application's own repository, so the published
page cannot drift from the one that governs it.

No fonts, scripts, analytics or images are loaded from anywhere else.
