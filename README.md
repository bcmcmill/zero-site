# Zero — site

The public page for [Zero](https://bcmcmill.github.io/zero-site/), debt-payoff planning software
that runs on the user's own device, together with its privacy policy.

This repository contains those pages only.

`privacy.html` is generated from the policy maintained alongside the application, so the published
page cannot drift from the one that governs it.

No fonts, scripts, analytics or images are loaded from anywhere else.
